
# AgriMarket AI — SIH Dashboard

A Streamlit prototype for:
**Strengthening Market Linkages and Price Discovery for Farmers**

## Features
- Current crop price
- Random Forest price prediction
- 7/15/30 day forecast
- Mandi comparison
- Transport-cost adjusted net value
- Best mandi recommendation
- Supply/arrival trend
- Weather indicator
- Farmer-facing AI recommendation

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

The dashboard currently uses demo-generated data. Replace it with official mandi,
arrival, weather and transportation datasets for the SIH final prototype.
